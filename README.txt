СОРТИРОВКА МАССИВА (GNOMESORT)
ОПИСАНИЕ ПРОЕКТА

Приложение предназначено для ввода, генерации и сортировки массивов целых чисел с использованием алгоритма Gnome Sort. Программа имеет графический пользовательский интерфейс и использует базу данных для хранения пользователей и истории выполненных сортировок.

Проект носит учебный характер и предназначен для изучения алгоритмов сортировки, принципов построения графических приложений и работы с базами данных.

ЗАПУСК И АВТОРИЗАЦИЯ

После запуска приложения пользователю предлагается выполнить вход или регистрацию. Для входа необходимо ввести логин и пароль. В случае неудачного входа поля ввода автоматически очищаются. После успешной регистрации поля ввода также очищаются, после чего пользователь может выполнить вход в систему.

ГЛАВНОЕ ОКНО ПРИЛОЖЕНИЯ

После успешной авторизации открывается основное окно приложения, предназначенное для работы с массивами чисел. В главном окне отображается таблица для ввода элементов массива, а также элементы управления генерацией, сортировкой и историей операций.

ВВОД МАССИВА

Ввод массива осуществляется в табличной форме. Редактирование элементов массива производится по двойному клику мыши или с клавиатуры. В ячейки таблицы разрешён ввод только целых чисел. При попытке ввода некорректных значений редактирование блокируется.

ГЕНЕРАЦИЯ МАССИВА

Приложение поддерживает автоматическую генерацию массивов случайных целых чисел. Пользователь задаёт минимальное и максимальное значение элементов, а также количество элементов массива. Минимальная и максимальная границы не могут быть равны, в противном случае генерация массива запрещается.

СОРТИРОВКА МАССИВА

Сортировка массива выполняется по нажатию соответствующей кнопки и реализована с использованием алгоритма Gnome Sort. Результат сортировки отображается пользователю сразу после завершения операции. Повторная сортировка одного и того же массива не сохраняется в историю, что предотвращает дублирование записей в базе данных.

ИСТОРИЯ СОРТИРОВОК

Все уникальные операции сортировки сохраняются в базе данных. История сортировок содержит исходный массив, отсортированный массив, а также дату и время выполнения операции. Пользователь может просматривать историю сортировок и очищать её при необходимости. Очистка истории сопровождается диалогом подтверждения.

РАБОТА С БАЗОЙ ДАННЫХ

База данных используется для хранения информации о пользователях и истории сортировок. Все данные сохраняются автоматически и остаются доступными после повторного запуска приложения.

ИНТЕГРАЦИОННЫЕ ТЕСТЫ

Для проверки корректности работы с базой данных и оценки производительности реализованы интеграционные тесты. Тесты выполнены в виде отдельного консольного приложения и не являются частью основного проекта. Для тестирования используется отдельная база данных SQLite.

Реализованы следующие тесты:
– тест добавления 100, 1000 и 10000 массивов с измерением времени выполнения;
– тест выгрузки и сортировки 100 случайных массивов, выполняемый три раза для баз разного размера, с вычислением общего и среднего времени работы;
– тест очистки базы данных, выполняемый три раза для различных объёмов данных.

Результаты выполнения тестов выводятся в консоль.

НАЗНАЧЕНИЕ ПРОЕКТА

Проект предназначен для использования в учебных и лабораторных работах, а также для демонстрации алгоритмов сортировки, работы с графическим интерфейсом и принципов интеграционного тестирования.
